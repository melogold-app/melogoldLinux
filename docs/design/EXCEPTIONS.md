# Исключения Melogold: Linux

Реестр по `docs/DESIGN-DOCTRINE.md` §3. Нет строки — нет исключения: всё остальное делается системными компонентами
(`docs/design/PLATFORM.md`, сверено 2026-10-07). Своё оформление — `crates/melogold-gtk/resources/style.css`; часть его
задана пользователем прямо (`docs/PROMPT.md` §5.1 «Оформление», 2026-09-30: «выглядит дёшево и жалко по сравнению с
другими платформами») — такие строки помечены «решение пользователя».
