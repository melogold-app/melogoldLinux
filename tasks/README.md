# Задания

Всё, что нужно сделать в Linux-клиенте, лежит здесь: одно задание — один файл `NNNN-название.md`. В задании — что нужно пользователю, решение и проверка. Основа клиента — `docs/PROMPT.md`.

Задания других клиентов, которые Linux делает в своих срезах (`docs/PROMPT.md` §10), лежат в `melogoldWindows/tasks/`, `melogoldAndroid/tasks/` и `melogoldiOSmacOS/tasks/`: клиенты ведут себя одинаково. Новое общее задание приходит сюда отдельным файлом.

## Как работать

1. В начале каждой сессии прочитай `docs/PROMPT.md` и этот файл.
2. Выполняй открытые задания по номерам, сразу. Задание со срезом делается вместе с ним (`docs/PROMPT.md` §7).
3. Каждое задание — срез: сборка и тесты → запуск → снимки окна → коммит → push.
4. Берёшь задание — статус «в работе»; сделал — «сделано», в том же коммите, что и работа. Хэш коммита в файл не пишется.
5. Если в задании что-то не решено или противоречит коду, спроси пользователя. Контракт сервера сам не меняй.

Статусы: `открыто` · `в работе` · `сделано`.
