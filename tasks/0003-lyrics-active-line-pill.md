# Синхронный текст: подложка под текущей строкой по размеру строки

Статус: открыто (делается в срезе 6, «Тексты»)

Те же задания и подробности: `melogoldAndroid/tasks/0010-lyrics-active-line-pill.md`,
`melogoldiOSmacOS/tasks/0012-lyrics-active-line-pill.md`. Образец — Windows
(`melogoldWindows/src/Melogold.App/Controls/SyncedLyricsView.cs`).

## 1. Что нужно пользователю

Пользователь о тексте на Windows: «мне очень сильно понравилась твоя реализация лирики с этим блоком посередине,
который подстраивается под размер текста, который в данный момент играет». На всех клиентах должно быть так.

## 2. Как должно быть

- Скруглённая подложка под текущей строкой **по размеру текста строки** (ширина самой длинной строки переноса,
  высота — вместе с подпевкой и переводом), не на всю ширину. Поля 16 × 10 и скругление 12 при базовом размере 28,
  масштабируются с размером текста. Дуэт справа — подложка справа.
- На следующую строку подложка **переезжает и меняет размер пружиной** (затухание 0.78, период ~70 мс), а не
  исчезает. Сдвинулась строка после раскладки — подложка догоняет.
- Нет текущей строки (до первой, проигрыш с точками) — подложка гаснет за 0,2 с.
- Цвет — `secondaryContainer` схемы из обложки (как фон «Сейчас играет»), без цвета обложки — белый 16 % на тёмном,
  чёрный 8 % на светлом.
- Щелчок по строке перематывает; подложка щелчков не перехватывает. «Уменьшить анимацию» (`gtk-enable-animations`
  выключено) — без пружины.
- Яркость строк: текущая 1, прошедшие 0.35, будущие 0.6.

## 3. GTK

- Подложку рисовать одним виджетом-наложением над списком строк (`GtkOverlay` или свой виджет с
  `gtk_snapshot_append_fill` скруглённого прямоугольника), не фоном каждой строки — иначе нет переезда.
- Пружина — `AdwSpringAnimation` (`adw_spring_params_new(0.78, 1, stiffness)`), цели — границы текущей строки из
  `gtk_widget_compute_bounds` относительно наложения.

## 4. Проверка

Снимки: короткая строка, длинная с переносом, подпевка, дуэт справа, проигрыш; запись переезда.
