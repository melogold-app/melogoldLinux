# Закреплённый текст песни: одинаковый на всех устройствах

Статус: сделано (срез 6, «Тексты») — контракт `melogoldServer/docs/API.md` §4.8 (`lyrics.pin.set`, `lyricsPins`); образец — Android 0.1.10

Общая часть (что нужно пользователю, порядок выбора текста, когда закреплять, как достать текст по ссылке) —
`melogoldWindows/tasks/0012-lyrics-pins.md`.

Коротко: прослушал трек 30 с с найденным автоматически текстом и не менял — текст закрепляется на сервере ссылкой
(поставщик + номер текста у него), и все устройства показывают его, а не ищут свой. Раз Linux пишется с нуля, сразу
храни у найденного текста ссылку у поставщика (id LrcLib, browseId YouTube Music, id и accesskey KuGou) — остальным
клиентам её пришлось добавлять потом.

## Linux

- у найденного текста сразу хранится ссылка у поставщика (`lyrics.synced_ref`, `plain_ref`, схема 8);
- `melogold-core/src/lyrics/pins.rs`: `pin_of`, `needs_pinned` (порядок: свой → закреплённый → поиск → общий),
  `from_pinned`, `shifted` (сдвиг «позже» уходит в закрепление, «раньше» остаётся здесь);
- закрепление — там, где плеер пишет прослушивание, после 30 с (`Library::pin_played`; первое закрепление — общее);
- синк — op `lyrics.pin.set` только при виде в `features.sync.kinds`, строки `lyricsPins` — и здесь, и в снимок;
- живая проверка двух устройств: закрепление с `startTimeMs` доходит до второго устройства.
