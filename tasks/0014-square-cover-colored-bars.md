# Обложка всегда квадратная: поля любого цвета и обводка скана

Статус: сделано

Пользователь прислал скриншот «Сейчас играет» на iPhone (2026-09-30): «кривой и не красивый». Одна из причин — обложка «Группы крови» (Кино) была прямоугольником 16:9 с коричневыми полями по бокам, а после их срезки — в толстой чёрной рамке.

- **Поля не только чёрные.** У видео-«статики» (обложка сингла в кадре 16:9) поля бывают любого ровного цвета: `FrameBars` искал только чёрные (канал ≤ 28), коричневые не срезал — кадр оставался широким.
- **Обводка скана.** Внутри полей (а у квадратных обложек YouTube Music — прямо по краю картинки) бывает рамка одного цвета со всех четырёх сторон: чёрная рамка скана конверта.

Так уже сделано на Apple (`MelogoldCore/Music/FrameBars.swift`, тесты `FrameBarsTests`), порт — сюда (`crates/melogold-core/src/frame_bars.rs`).

## Правило

1. **Поля:** линия — поле, если ≥ 98 % её пикселей в пределах ±24 по каналу от цвета крайней линии этой стороны (крайняя линия сама должна быть почти однотонной); поля с двух сторон — **одного цвета** (±40 по каналу), одинаковой ширины (разница ≤ 3 % стороны), вместе ≥ 3 % стороны, остаток ≥ 40 %. Сначала сверху-снизу, потом по бокам в оставшихся строках.
2. **Обводка:** внутри того, что осталось, — рамка одного цвета (цвет верхней строки) со **всех четырёх** сторон, каждая сторона от 1 px до 6 % стороны; срезается вместе с ещё 0,5 % стороны (размытая граница JPEG, иначе остаётся тёмный волосок).
3. **Где:** кадр видео (`i.ytimg.com/vi/…`) — поля и обводка; любая другая обложка (YouTube Music, `lh3`/`yt3`) — только обводка. Для обложки в системе (уведомление, SMTC/MPRIS) — так же, потом центральный квадрат.

## Проверка

Юнит-тесты (как у Apple): коричневые поля с шумом JPEG срезаются; слева коричневое, справа синее — не поля; ровное небо только с одной стороны — не поле; коричневые поля и внутри чёрная обводка 6 px — срезается всё; квадратная обложка с чёрной обводкой 5 px без поиска полей — срезается обводка; широкий ровный фон обложки (25 %) без поиска полей — остаётся; прежние случаи (чёрные поля, тёмная сцена, почти чёрный кадр, тонкая кромка) — как были. Живая проверка: «Кино — Группа крови» в «Сейчас играет» — квадрат без рамки.

## Сделано на Linux

Поля и обводка — `melogold-core/src/frame_bars.rs` (кэш картинок режет при разборе); обложка для рабочего стола — `mpris.rs`: картинку «Сейчас играет», уже без полей и обводки, окно режет по центру в квадрат, кладёт PNG в `~/.cache/melogold/mpris` и отдаёт в `mpris:artUrl` как `file://`.
