# «Диагностика»: журнал одним файлом

Статус: сделано (31.10.2026), не выпущено.

Максим (31.10.2026): «сделай во всех клиентах, чтобы логи уходили файлом». Повод — Android: журнал Романа не
поймал обрыв музыки (Android, задание 0035). Здесь журнал и так пишется файлами (`logs/current.log`, `previous.log`,
`last-crash.txt`), но чтобы отправить его, надо было открыть папку и приложить три файла.

## Сделано

- «Настройки → Диагностика → Журналы»: строка «Журнал одним файлом» с кнопкой «Сохранить…» — диалог сохранения
  (по умолчанию «Документы», имя `melogold-log-ГГГГММДД-ЧЧММ.txt`), после — «Файл сохранён» с «Открыть».
- Файл: версии (Melogold, GTK, libadwaita, система) и время, затем «Падение», «Прошлый запуск», «Этот запуск» —
  `logging::export`; разделители те же, что у Android и Windows (`===== Название (файл) =====`).
- Тест `export_is_the_header_then_crash_previous_and_current`; снимок страницы —
  `~/Pictures/melogold-log-file-20261031/1280x800-light-ru/05-diagnostics.png`.

Windows — задание 0039 в `melogoldWindows`.
