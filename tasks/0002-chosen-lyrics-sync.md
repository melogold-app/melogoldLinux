# Выбранный текст песни переезжает на другие устройства

Статус: открыто (делается в срезе 6, «Тексты»)

Те же задания и подробности: `melogoldAndroid/tasks/0009-chosen-lyrics-sync.md`,
`melogoldiOSmacOS/tasks/0011-chosen-lyrics-sync.md`. Образец — Windows 0.1.10 (`StoredLyrics.Chosen`,
`LyricsSyncRules.IsOwn`, `LibrarySync.ApplyLyrics`; коммиты `262c146`, `845d1de`).

## 1. Что нужно пользователю

Текст, выбранный в «Найти другой текст» (LrcLib), должен появиться и на других устройствах, как свой набранный. Раньше
его приходилось искать на каждом устройстве заново.

## 2. Как сделать сразу правильно

- У локального текста трека — флаг «выбран» (`chosen`).
- **Свой** = сторона из `user`/`file` **или** флаг и непустой текст. Свой уходит на сервер (API §4.10) с настоящим
  источником: `lrclib`, `youtube_music`, `kugou`.
- Флаг ставится: выбор в «Найти другой текст»; своя версия, пришедшая с сервера, — **с любым источником**; найденный
  автоматически текст, совпавший с пришедшей своей версией.
- Найденный автоматически без флага на сервер не уходит.
- **Грабля, на которой споткнулись Android и Apple:** версию с сервера с источником `lrclib` они сохраняли как
  найденную, не считали своей и при следующей выгрузке отправляли `DELETE` — выбор стирался на всех устройствах.
  Всё, что пришло из своих версий сервера, — своё.

## 3. Проверка

- Юнит-тесты: выбранный LrcLib — свой, уходит с `syncedSource = "lrclib"`; без флага — не уходит; версия с сервера с
  `lrclib` сохраняется с флагом и не удаляется при следующей выгрузке.
- Живой сервер (временный аккаунт, удалить после): выбор на Windows появляется на Linux и обратно.
